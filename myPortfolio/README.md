# IT Student Portfolio

A personal portfolio website for an Information Technology diploma student.

## Files
- `index.html` — portfolio page content
- `css/style.css` — layout, colours, responsive styles, and theme styles
- `js/script.js` — mobile navigation, light/dark theme toggle, current year, and reveal animations

## Run locally
1. Keep the folder structure unchanged.
2. Open `index.html` in a web browser, or use Live Server in Visual Studio Code.

## Before publishing
- Replace the placeholder email with the email address you want to use publicly.
- Replace the generic GitHub and LinkedIn links with your own profile links.
- Add a profile photo if you want one.
- Check the certificate names against the official certificates and add links if available.
- Make sure each project description accurately reflects your own work and the features that are actually complete.
- Ask permission before publishing code or materials from group projects.
